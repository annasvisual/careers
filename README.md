# London bank jobs

Простая лента новых вакансий по дням для GitHub Pages. Источники: Monzo, Triodos, Lloyds, Starling, Nationwide, NatWest. Нет аккаунтов соискателя и истории откликов.

## Статус

Первая версия. Фильтры и обработка истории покрыты локальными тестами. Полный сбор через Python/Chromium ещё нужно проверить с доступом в интернет; проверка сайтов в браузере ранее подтвердила доступность пяти источников. Triodos возвращал пустой список и пока считается непроверенным: скрипт отразит это как неполную проверку. Разметка и пагинация сайтов могут меняться.

## Правила

- London среди локаций, в том числе hybrid и несколько офисов. UK remote без явно указанного London по умолчанию не включён.
- Marketing: performance, affiliate, web, product, PPC, paid media/social/search. Без Head, Lead, SEO, CRM, email, PR, communications. Senior и Manager пока разрешены.
- Junior product, включая Junior Product Designer.
- Junior/early careers finance: finance/accounting/audit/tax/treasury/credit/risk/investment/markets/corporate banking. Без sales, business development, compliance/financial crime, operations и технических ролей. Analyst/Associate без подтверждения начального уровня не включаются. Предварительный предел требуемого опыта — 2 года; правила эвристические, а не оценка соответствия кандидата.
- Первая успешная проверка каждого источника сохраняет исходный список без выдачи его за новые вакансии. Далее дата означает первое обнаружение трекером, а не дату публикации работодателем.
- ID сохраняются даже для неподходящих вакансий: смена фильтра не выдаст старую позицию за новую. Изменение ID работодателем может выглядеть как новая вакансия.
- Повторный запуск в тот же день дополняет ленту без дублей. Архив не удаляется при закрытии вакансии.
- Пустые последовательные дни объединяются только после успешных проверок. Сбой сайта показывается как `Check incomplete`. Необъяснимый пустой список считается ошибкой, чтобы не заявлять об отсутствии вакансий без подтверждения.

## Запуск на GitHub

1. Создать репозиторий и загрузить содержимое этой папки, включая `.github`.
2. Основную ветку назвать `main` (либо изменить `update.yml`).
3. В Settings → Pages → Source выбрать GitHub Actions.
4. Разрешить Actions запись в репозиторий, если политика организации её ограничивает. Защита main должна допускать коммиты бота либо потребуется отдельная ветка данных.
5. В Actions запустить `Check vacancies and publish` вручную. После первого запуска проверить отчёт по каждому источнику. При сбое страница публикует предупреждение, а запуск отмечается красным.

Расписание: ежедневно 08:00 UTC (08:00 зимой и 09:00 летом в London). GitHub может задерживать запуски. В неактивных публичных репозиториях расписание может быть отключено GitHub. Публикуется только HTML и данные ленты, а не скрипт/конфигурация. Сам репозиторий при выборе public будет доступен целиком.

## Локально

Python 3.12+

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
python scripts/update_jobs.py
python -m http.server 8000
```

Открыть http://localhost:8000. `index.html` читает `data/jobs.json`; прямое открытие файла без сервера не подходит.

Для безопасного теста без изменения основной истории скопировать `data/jobs.json` и передать `--data /absolute/path/test-jobs.json`.

## Ограничения

Скрипт читает публичные страницы, не обходит CAPTCHA или ограничения доступа. При изменениях сайтов адаптеры требуют обслуживания. Детали подходящих по названию вакансий проверяются отдельно, поэтому Nationwide с радиусом 200 миль не добавит автоматически все города. Первый пустой ответ источника требует проверки, а не автоматического признания нулевого результата.
